
# Sistema Integral de Gestion - Software FJ

## Descripcion
Proyecto desarrollado en Python para gestionar clientes, servicios y reservas de la empresa Software FJ.

## Funcionalidades
- Registro y validacion de clientes.
- Gestion de servicios especializados.
- Reservas, confirmaciones y cancelaciones.
- Calculo de costos con descuentos e impuestos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores en archivos de log.
- Uso de programacion orientada a objetos, herencia, abstraccion y polimorfismo.

## Tecnologias utilizadas
- Python 3
- Programacion Orientada a Objetos
- Visual Studio Code

## Ejecucion
Para iniciar el programa, abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
python main.py
```
